# Умные приключения: Скорочтение и развитие мозга

Интерактивное веб-приложение для тренировки памяти, внимания, логики, скорости чтения и ловкости в игровом формате.

**🔗 Демо:** [https://fanfestportal-ai.github.io/uchi.ru_game/](https://fanfestportal-ai.github.io/uchi.ru_game/)

## Описание

«Умные приключения» — это браузерная игра для детей в возрасте от 6 до 11 лет, направленная на развитие уровня чтения, скорости чтения и когнитивных способностей. Проект включает 5 категорий заданий с тремя уровнями сложности, системой прогресса, сохранением статистики и фиджитал-механиками.

## Возможности

- 5 категорий: чтение, логика, внимание, память, ловкость
- 3 уровня сложности: Новичок (⭐), Мастер (⭐⭐), Эксперт (⭐⭐⭐)
- Система очков, комбо и серий (5 правильных ответов подряд дают +50)
- Автосохранение прогресса и рекордов в localStorage
- Фиджитал-задания с подтверждением через родительский пароль
- Детальная статистика: очки, точность, количество ошибок, общее время

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, неоморфный дизайн, адаптивная вёрстка)
- JavaScript ES6
- Web Speech API (озвучивание слов)
- Canvas API (обведение фигур)

## Как играть

1. Выберите категорию (Чтение / Логика / Внимание / Память / Ловкость)
2. Выберите уровень сложности: Новичок (⭐), Мастер (⭐⭐) или Эксперт (⭐⭐⭐)
3. Выберите конкретное задание из списка
4. Выполняйте задания и набирайте очки
5. Каждые 10 успешных заданий завершают уровень
6. Для фиджитал-заданий требуется пароль родителей: `UNO_MISS_DI`

## Типы заданий

| Категория | Примеры заданий |
|-----------|----------------|
| Чтение    | Перевёрнутый текст, Текст с препятствиями, Зеркальный текст, Раздели на слова |
| Логика    | Продолжи цепочку, Загадки, Анаграммы, Расшифруй послание, Соедини части |
| Внимание  | Найди лишнее, Найди предметы, Таблицы Шульте, Зачеркни-обведи |
| Память    | Запомни порядок, Что пропало?, Мини-опрос, Запомни на слух |
| Ловкость  | Реакция, Найди слова, Таблица Шульте |

## Система очков

- Правильный ответ: `10 + комбо × 2`
- Комбо увеличивается после каждого правильного ответа
- При ошибке комбо сбрасывается
- Серия из 5 правильных ответов: +50 бонусных очков

## Хранение данных

Все данные сохраняются в localStorage браузера:

| Ключ                   | Данные |
|------------------------|--------|
| `umnye_priklucheniya`  | Очки, статистика, рекорды |
| `quiz_answers`         | Ответы на мини-опросы |
| `audio_words`          | Слова для фиджитал-задания |
| `reaction_record_1/2/3`| Рекорды реакции |
| `schulte_record_1/2/3` | Рекорды Шульте |
